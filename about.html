Architecting Trevalart.com: Zero-Bloat Art Showcases with Edge CDN Caching

A deep dive into how I built Trevalart.com from scratch, focusing on rapid asset loading, accessible modal lightboxes, responsive WebP image pipelines, and continuous deployment workflows.

When creating a portfolio for fine art and geometric illustrations, visual fidelity cannot be compromised, yet slow image loading kills engagement. For Trevalart.com, I intentionally avoided multi-megabyte JavaScript frameworks in favor of semantic HTML5, modern CSS Grid, and vanilla ES6+.

By configuring an automated image optimization pipeline converting assets to WebP with responsive srcset fallbacks, and serving them via global edge CDN nodes, images render crisply within milliseconds. Pairing that with automated Git-driven CI/CD deployment ensures any new piece added to the repository goes live immediately with zero manual server configuration.

From 480V Switchgear to Clean Code: What Commercial Electrical Taught Me About Software

Commercial electrical work demands total respect for physical reality: a bad wire termination or bypassed safety check causes fires. Translating that high-stakes craftsmanship into software engineering produces dramatically more dependable systems.

Working in West Palm Beach on active commercial job sites for Maeiser Electric via QLM requires meticulous coordination. You don't guess whether a 480-volt 3-phase feeder is energized; you test, verify, lock out, and trace the path methodically.

In software development, especially in modern web frameworks, developers often treat unexpected exceptions with reckless band-aids or layers of boilerplate. But when you adopt an electrician's mindset, you design software with clean circuit breakers, bounded error boundaries, explicit failure modes, and clear diagnostic telemetry. Craftsmanship isn't just about how an app looks—it's about how gracefully it behaves under load and failure.

Sacred Geometry & The Mathematical Soul of User Interfaces

Why geometric art and harmonic ratios aren't just aesthetic hobbies, but foundational principles that make software interfaces intuitively harmonious to human cognition.

When drawing isometric cubes, Metatron’s Cube, or golden spirals, you realize that visual balance is pure mathematics: proportional scales, harmonic intervals, and spatial equilibrium.

Digital interfaces that feel 'clunky' almost always violate fundamental geometric rhythm. By bringing harmonic proportions into UI spacing systems (8-point grids, Fibonacci scale margins, and fluid clamp typography), software stops feeling like a collection of boxes and starts feeling like an organic, harmonious instrument.
